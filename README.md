Yeah 😅 and honestly, that's a much more sensible break goal than "I need to learn programming."

You don't need to collect languages like Pokémon. 😂

For your capstone, Python + CSS can be a focused exploration:

Python → learn enough programming logic to build/modify useful backend or automation pieces.

CSS → understand how interfaces are structured and styled, even if you're not aiming to become a front-end developer.

Your existing networking knowledge → keep developing this because that's already aligned with your NDM direction.

Systems analysis/design → probably the part worth developing alongside the technical skills, because that's where your natural interest seems strongest.

And I wouldn't make the goal:

"By the end of break, I must master Python and CSS."

More like:

"By the end of break, I want to be capable of opening a small project, understanding what the pieces are doing, changing something myself, and troubleshooting when it breaks."

That's a much more useful threshold for you.

Especially because you're already discovering that you enjoy the exploration → problem → system → solution cycle. If Python eventually becomes another tool that lets you turn your ideas into working systems, great. If CSS teaches you how the interface layer works, great.

And if you spend three hours fighting with a tiny Python error and eventually go:

"OH. THAT'S WHY IT DID THAT."

😂

That's learning too.

You don't need to come out of break as a programmer. You just need to become a little more technically dangerous than you were before. 😆
